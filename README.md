# Installation

```bash
apt update && apt upgrade -y
pkg install git
git clone https://github.com/lacongai/Termux-os
cd Termux-os
bash os.sh

```


# Reinstall the Tool

## 1. Xóa tool cũ
```bash
rm -rf ~/Termux-os
```

## 2. Clone lại mới
```bash
cd ~
git clone https://github.com/lacongai/Termux-os
```

## 3. Vào thư mục
```bash
cd ~/Termux-os
```

## 4. Chạy lại file
```bash
bash os.sh
```
